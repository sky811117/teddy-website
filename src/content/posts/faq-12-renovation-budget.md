中古屋翻新最常踩的雷,不是找錯工班,是「**預算抓太少**」。

而預算會抓太少,通常都卡在同一個地方:**報價單上沒有寫的東西,不代表不用做**。

最典型的就是水電管線。一份 30 坪老屋的報價單如果只寫「油漆、地板、衛浴、廚房、油煙機、冷氣」,看起來項目很齊全、金額也漂亮 — 但屋齡 28 年的水管跟電線,報價單裡一個字都沒提,那就是**不換**。等你住進去才發現要換,牆面剛做好的全部要打掉重來。

這篇把 30 坪老屋翻新的錢會花到哪裡,一塊一塊拆給你看。

> 📌 **先講清楚**:以下所有價格都是市場上常見的區間,不是報價。實際金額會因為屋況、建材等級、地區、工班而差很多,一切以你手上的正式報價單為準。

---

## 一句話直接答案

**30 坪中古屋翻新標準預算 50-100 萬,簡裝 15-45 萬,高規 100-150 萬以上**。

無論哪個等級,都要**預留 10-15% 預備金**應付拆開後發現的意外。

📌 這篇是 **30 坪、逐項拆到細項**的預算表,用來對報價單。如果你想先知道「基礎整理、中度翻新、完整重做差在哪」「該找設計師統包還是自己發包工班」,那是另一篇:[中古屋裝潢費用怎麼抓?3 種翻新等級差在哪、工班怎麼挑](/posts/viewing-05-renovation-budget/)。

## 三個翻新等級 — 每坪預算對照表

| 等級 | 每坪預算 | 30 坪總價 | 適合對象 |
|------|---------|----------|---------|
| **簡裝** | 5,000-15,000 元 | 15-45 萬 | 投資出租、過渡自住、預算極限 |
| **標準** | 15,000-30,000 元 | 50-100 萬 | 一般自住、想住 10-15 年 |
| **高規** | 30,000-50,000 元 | 100-150 萬+ | 長住、要設計感、進口建材 |

### 簡裝包含什麼

- 全屋油漆(乳膠漆)
- 拋光地板或塑膠地板
- 換衛浴設備(臉盆、馬桶、淋浴)
- 換廚房檯面、烘碗機
- 簡單木工(電視牆、玄關櫃)

### 標準包含什麼

- 簡裝所有項目
- **更換水電管線**(整套換新)
- **更換廚房水槽 + 全套廚具**
- **更換衛浴防水 + 排水**
- 系統櫃(臥室衣櫃、書房)
- 冷氣 + 安裝
- 燈具 + 開關

### 高規包含什麼

- 標準所有項目
- 設計師全程設計監工
- **動格局**(打牆、加牆、改動線)
- 進口建材
- 收納與動線的整體規劃(玄關、廊道)
- 智慧家電整合

## 重點項目 5 大花費明細

> ⚠️ **以下用一戶「30 坪、屋齡約 28 年、做標準等級翻新」的假設情境示範,不是真實案件的報價。**

### 項目 1:水電管線(7-15 萬)

**最不能省的項目**。

老屋 30 年的水管(鍍鋅鋼管)會生鏽,漏水機率高;電線老化會跳電,用電量大的家電一起開更吃緊。

| 細項 | 預算 |
|------|------|
| 換全屋電線(30 坪) | 3-6 萬 |
| 換全屋水管 + 排水 | 3-6 萬 |
| 加裝專用迴路、無熔絲開關 | 1-2 萬 |
| 弱電(網路、電視) | 5,000-1 萬 |

**全套合計:7-15 萬**。

⚠️ 預算極限時可只換主幹線、保留分支,但**不建議省這個** — 這是唯一一個「事後要補做,前面做好的都要打掉」的項目。

### 項目 2:衛浴廚房(14-30 萬)

**濕區風險最高**。防水沒做好,2-3 年後會用漏水、發霉來提醒你。

| 細項 | 預算 |
|------|------|
| 衛浴(2 套):防水 + 設備 + 磁磚 | 8-15 萬 |
| 廚房:水槽 + 廚具 + 油煙機 + 排油煙管 | 5-12 萬 |
| 浴缸或淋浴間玻璃 | 1-3 萬 |

**全套合計:14-30 萬**。

⚠️ **防水千萬不能省**。漏到樓下要賠、要重做,算下來比一開始做好貴得多。

### 項目 3:油漆地板(10-20 萬)

**視覺感受最直接**。新油漆 + 新地板,空間就煥然一新。

| 細項 | 預算 |
|------|------|
| 全屋油漆(批土 + 乳膠漆) | 6-10 萬 |
| 拋光地板(超耐磨) | 5-10 萬 |
| 木地板(實木 / 海島型) | 8-15 萬 |
| 磁磚(客廳、玄關) | 4-8 萬 |

**全套合計:10-20 萬**。

### 項目 4:系統櫃 / 木工(10-25 萬)

| 細項 | 預算 |
|------|------|
| 玄關櫃 | 2-5 萬 |
| 主臥衣櫃 | 3-8 萬 |
| 書房櫃 + 書桌 | 3-6 萬 |
| 電視牆 + 矮櫃 | 2-5 萬 |
| 床頭板 | 1-3 萬 |

**全套合計:10-25 萬**。

⚠️ 木工 vs 系統櫃:木工單價高、但可以配合畸零空間做;系統櫃相對便宜、工期短、品質穩定,適合預算要控住的人。

### 項目 5:軟裝家具(另計,30-70 萬)

**軟裝是「裝潢預算外」的另一筆錢**,很多人會漏算。

| 細項 | 預算 |
|------|------|
| 沙發 | 3-8 萬 |
| 餐桌椅 | 2-5 萬 |
| 床墊 + 床架(主臥) | 3-10 萬 |
| 冰箱 + 洗衣機 + 烘衣機 | 5-12 萬 |
| 冷氣(全屋 3 台) | 6-12 萬 |
| 燈具 | 2-5 萬 |
| 窗簾 | 2-5 萬 |
| 飾品、雜物 | 3-10 萬 |

**全套合計:30-70 萬**。

## 30 坪預算總表 — 標準翻新

把上面 5 個項目合在一起(同樣是假設情境,示範怎麼加總):

| 項目 | 預算範圍 | 中位數 |
|------|---------|--------|
| 水電管線 | 7-15 萬 | 10 萬 |
| 衛浴廚房 | 14-30 萬 | 20 萬 |
| 油漆地板 | 10-20 萬 | 15 萬 |
| 系統櫃 / 木工 | 10-25 萬 | 17 萬 |
| **裝潢小計** | **41-90 萬** | **62 萬** |
| 預備金(10-15%) | 4-13 萬 | 8 萬 |
| **裝潢總計** | **45-103 萬** | **70 萬** |
| 軟裝家具(另計) | 30-70 萬 | 45 萬 |
| **全部加總** | **75-173 萬** | **115 萬** |

⚠️ **「裝潢預算」跟「軟裝預算」要分開抓**。買房時只編了裝潢預算,交屋才發現家電、家具、窗簾還要再一筆,是很常見的狀況。

## 為什麼一定要留預備金

老屋拆開後**常見的意外**:

1. **牆內水管爛掉**(原本沒打算換,看到爛掉只好補) → 多 3-5 萬
2. **地板下空腐 / 白蟻**(撕掉地板才看到) → 多 2-5 萬
3. **樑柱裂縫 / 鋼筋外露**(批土時才發現) → 多 3-8 萬
4. **磁磚剝離**(拆掉舊磁磚才發現底層鬆動) → 多 2-4 萬
5. **電線比預期老化**(換到一半才發現電盤要換) → 多 1-3 萬

**這些都是「拆了才知道」的**,不是工班報價不實在,是真的看不到。

**編 80 萬的工程,最後做到 88-92 萬是常見的**。預備金沒留,你只能中途加碼,或是砍掉後面的項目 — 而被砍掉的通常是軟裝,住進去會很有感。

## 給讀者的 action items

要翻新中古屋讀完做這 5 件事:

1. ✅ 找 2-3 家工班 / 設計師報價,**報價單必須項目明細齊全**(別只給總價)
2. ✅ 確認報價單有沒有寫「**水電管線換新**」(沒寫就是不換)
3. ✅ 預備金抓總預算的 10-15%
4. ✅ 軟裝家具預算另計,別併入裝潢預算
5. ✅ 簽約前確認**付款方式與各期驗收條件**(分期比一次付清安全)
