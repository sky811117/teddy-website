# Cloudflare Pages _headers — 靜態資源快取策略
#
# 設計原則：
# - 圖片 / 字型 / built CSS-JS：immutable (1 年)、Cloudflare hash 在 filename 已天然 cache-busting
# - HTML：no-cache (每次 revalidate、新 deploy 立刻生效)
# - OG 圖：1 個月；物件照：1 天 + stale-while-revalidate 7 天（同路徑覆寫、不會 hash bust）
# - ⚠️ 一條規則只能有一個 `*`（Cloudflare Pages 限制），雙 splat 會整條被忽略
# - robots / sitemap：1 天
#
# 注意：本檔 build 後會由 scripts/postbuild-headers.mjs rename 為 dist/_headers
# (Vite/Rollup 對 public/_headers 無副檔名會試 parse JS 報錯，故用 .txt 規避)

# OG images (1 個月)
/og/*
  Cache-Control: public, max-age=2592000, stale-while-revalidate=86400

# 物件照 — 一條規則只能有一個 splat（Cloudflare 官方限制，`/properties/*/*.jpg`
# 雙 splat 整條被忽略，線上實測 2,982 張照片全是 max-age=0）。`*` 會跨越 `/`，
# 所以 `/properties/*.jpg` 同時吃到 /properties/0066565/photo_03.jpg，
# 帶副檔名也不會誤中 /properties/0066565/ 的 HTML。
# 物件照是每晚「同路徑覆寫」（不是 hash 檔名），所以只鎖 1 天 + 背景更新 7 天，
# 換首圖 / 補拍重傳最晚隔天就會換過來，而不是黏 30 天。
/properties/*.jpg
  Cache-Control: public, max-age=86400, stale-while-revalidate=604800

/properties/*.png
  Cache-Control: public, max-age=86400, stale-while-revalidate=604800

/properties/*.webp
  Cache-Control: public, max-age=86400, stale-while-revalidate=604800

# 圖卡 / 社群素材 (1 個月)
/cards/*
  Cache-Control: public, max-age=2592000, stale-while-revalidate=86400

/communities/*
  Cache-Control: public, max-age=2592000, stale-while-revalidate=86400

  Cache-Control: public, max-age=2592000, stale-while-revalidate=86400

/photos/*

# Logo / favicon (1 個月)
/logos/*
  Cache-Control: public, max-age=2592000

/favicon.svg
  Cache-Control: public, max-age=2592000

/favicon.ico
  Cache-Control: public, max-age=2592000

/default-og.jpg
  Cache-Control: public, max-age=2592000

# Astro built assets (hashed filename → 1 年 immutable)
/_astro/*
  Cache-Control: public, max-age=31536000, immutable

# Pagefind 搜尋 index (1 天，新文章 deploy 後客戶端需更新)
/pagefind/*
  Cache-Control: public, max-age=86400, stale-while-revalidate=3600

# sitemap / robots (1 天)
/sitemap-*.xml
  Cache-Control: public, max-age=86400

/robots.txt
  Cache-Control: public, max-age=86400

/rss.xml
  Cache-Control: public, max-age=3600

# 站內工具資料（門牌定位庫 tc-addr、學區、垃圾車、嫌惡設施）與工具 JS
# 資料每月～每年才更新一次，頁面引用時帶 ?v=版本，所以 1 天快取＋背景更新 7 天就夠；
# 原本走預設 max-age=0，每查一次地址都要多發一輪 304。
/data/*
  Cache-Control: public, max-age=86400, stale-while-revalidate=604800

/js/*
  Cache-Control: public, max-age=86400, stale-while-revalidate=604800

# Security headers — 全站

# 原本是 geolocation=()＝整站禁止定位，嫌惡設施地圖的「用我的位置」在正式站一直按了沒反應（2026-09-29 發現）。
/*
  X-Content-Type-Options: nosniff
  X-Frame-Options: SAMEORIGIN
  Referrer-Policy: strict-origin-when-cross-origin
  Permissions-Policy: camera=(), microphone=(), geolocation=(self)
